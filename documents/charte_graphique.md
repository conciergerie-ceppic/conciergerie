# 🎨 Charte Graphique --- Premium Experience

## 1️⃣ ADN visuel

**Positionnement :** - Luxe discret\
- Élégance moderne\
- Exclusivité\
- Ambiance feutrée / nocturne\
- Expérience haut de gamme

Inspirations : hôtellerie 5★, conciergerie privée, aviation business.

## 🎨 2️⃣ Palette de couleurs

### 🖤 Noir profond (fond principal)

`#0B0B0D`\
Utilisation : - Background principal\
- Navbar\
- Sections premium

### 🌑 Gris anthracite

`#1A1A1F`\
Utilisation : - Sections alternées\
- Cartes\
- Footer

### ✨ Or premium (accent principal)

`#C6A75E`\
Utilisation : - Logo\
- Hover menu\
- Boutons primaires\
- Icônes

### 🤍 Blanc cassé (texte principal)

`#F5F5F3`\
Utilisation : - Titres\
- Texte principal

### 🌫 Gris clair secondaire

`#B8B8B8`\
Utilisation : - Texte secondaire\
- Descriptions\
- Sous-titres

### Exemple configuration Tailwind

``` js
colors: {
  primary: "#C6A75E",
  dark: "#0B0B0D",
  darkSoft: "#1A1A1F",
  light: "#F5F5F3",
  muted: "#B8B8B8",
}
```

## ✍️ 3️⃣ Typographies

### 🔠 Titres (élégance & impact)

**Option 1 (très premium) :** - Playfair Display

**Option 2 (plus moderne luxe) :** - Cormorant Garamond

Usage : - H1\
- Titres sections\
- Hero

### 🔤 Texte courant

-   Montserrat\
    ou\
-   Inter

### ✅ Recommandation idéale :

Titres → Playfair Display\
Texte → Montserrat

------------------------------------------------------------------------

## 🔘 4️⃣ Boutons

### Bouton principal

Fond : Or `#C6A75E`\
Texte : Noir profond\
Hover : `#B8964A`

Style : - Rounded-xl\
- Tracking légèrement augmenté\
- Majuscules

Exemple Tailwind :

``` html
class="bg-primary text-dark px-6 py-3 rounded-xl uppercase tracking-wider hover:opacity-90 transition"
```

### Bouton secondaire

Fond : Transparent\
Border : Or\
Texte : Or

Hover : - Fond noir\
- Texte or

------------------------------------------------------------------------

## 🧩 5️⃣ Icônes

Style recommandé : - Icônes outline fines\
- Couleur : Or ou Blanc cassé\
- Minimalistes

Bibliothèques recommandées : - Heroicons\
- Lucide\
- Phosphor Icons

À éviter : - Icônes cartoon\
- Icônes pleines épaisses\
- Icônes multicolores

------------------------------------------------------------------------

## 🧱 6️⃣ Ombres & Effets

Style luxe = subtilité.

Utiliser : - shadow-xl\
- backdrop-blur\
- Transparences légères

Exemple navbar :

``` html
bg-black/30 backdrop-blur-md
```

------------------------------------------------------------------------

## 📐 7️⃣ Règles UI importantes

✔ Espacements généreux (le luxe respire)\
✔ Maximum 3 couleurs dominantes\
✔ Animations lentes (duration-300 / duration-500)\
✔ Pas de bordures agressives\
✔ Préférer ombres et contrastes doux
